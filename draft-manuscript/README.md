# Draft Manuscript

This folder contains a ChemRxiv-style preprint draft for the package-scoped
materials and chemistry skills project.

- `main.tex`: self-contained LaTeX manuscript with embedded references.
- `figures/skill_improvement_bar.pdf`: vector bar graph generated from
  `eval/extension-score-summary.json`.
- `figures/skill_improvement_bar.png`: raster copy for quick preview.

Build locally with:

```bash
pdflatex main.tex
pdflatex main.tex
```
